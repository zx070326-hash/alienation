01Preprint

ETALON

Agentic computer-aided drug design

A harness that gives a general-purpose coding agent an environment for drug design. MolQuarry keeps chemical and biological evidence, MolCascade handles preparation, screening, and docking, and PRISM handles generation and physical modeling. The execution record separates completion, verification, and admission, so an unfinished computation is not stored as a negative result.

Xin Zheng contributed equally with Zhaoqi Shi and Xufan Gao. The affiliation is Chu Kochen Honors College and Future Learning Center, Zhejiang University. Posted on ChemRxiv on 2 November 2026. Not peer reviewed. The code is AIB001/ETALON, Apache-2.0, not under this account. That repository was last pushed on 5 November 2026.

TherapyMind

A research prototype for counseling dialogue

A counseling agent assembled by compiling prompt modules, with Chinese cultural constraints in the prompt rather than a fine-tune. It is a research prototype, not a deployed clinical service. CITATION.cff cites the software. This page does not call it a paper.

Public version 3.7.0. The author line is Xin Zheng, Zhejiang University. Public commits stop on 9 May 2026.

ai-native4material-web

Photothermal metamaterials, as a static report

A computational delivery for two fixed designs: a transparent radiative cooler, and a structure that responds to both voltage and temperature. The pages say manufacturability is still open, so this is not a fabrication-ready design. The research repository needs access. This site is the public static result.

The repository says the research stays paused. The report is updated through 2 November 2026. The site repository was still pushed on 7 November 2026. GitHub Pages loads.

05Demo

cike-dbt-demo

A DBT self-help dialogue prototype

A mobile-first demo for internal tests with adults. It handles crisis and clinical boundaries first, then retrieves passages that can be traced. It is not diagnosis or treatment, and it does not replace a counselor or a physician. Without a model key, retrieval, citation, and the safety boundary can still be shown.

The repository says commercial use of the two books is unconfirmed, so there is no public deployment and no GitHub Pages site. Last push 19 August 2026.
